# 바이러스 게임 관리

React + TypeScript + Vite 기반의 교실용 게임입니다. 현재 릴리스는 **v1.1.0**입니다. 서버, API 키, 환경변수 설정 없이 실행할 수 있습니다.

```sh
npm ci
npm run dev
```

기본 개발 서버는 보안을 위해 이 컴퓨터(`127.0.0.1`)에서만 열립니다. 같은 교실 네트워크의 다른 기기에서 접속시켜야 할 때만 방화벽과 네트워크 신뢰 여부를 확인한 뒤 `npm run dev:lan`을 사용하세요. 실제 운영 배포는 `npm run build`로 생성한 `dist` 정적 파일을 사용합니다.

- `npm run lint`: TypeScript 검사
- `npm test`: 게임 판정·저장·오디오 회귀 테스트
- `npm run build`: 배포용 `dist` 생성

## 자동 저장과 이어하기

설정 완료 항목과 진행 상태(학생, 점수, 감염 상태, 라운드, 남은 시간, 접촉 이력, 로그)는 같은 브라우저의 localStorage에 자동 저장됩니다. 제한 시간 입력은 ‘다음 단계’를 눌렀을 때 확정됩니다. 새로고침 후 시작 화면의 **이어하기**를 누르면 복구됩니다. 게임은 항상 일시정지 상태로 복구되며, 창을 닫아 둔 시간은 차감하지 않습니다. 마지막 타이머 저장 시점 기준 최대 약 1초 차이가 있을 수 있습니다.

저장된 게임이 있을 때 새 게임을 시작하면 교체 확인을 받습니다. 강제 종료 또는 결과 화면의 ‘처음으로 돌아가기’는 저장 기록을 삭제합니다. 저장 실패는 화면에 표시됩니다. 저장 데이터가 손상되었으면 복구하지 않고 경고를 표시합니다.

다른 기기·브라우저·주소로 자동 동기화되지 않습니다. 공용 기기에는 학생 이름과 게임 기록이 남으므로 사용 후 게임을 종료하세요. 시크릿 모드 종료나 브라우저 데이터 삭제 시 저장이 사라질 수 있습니다.

학생 명단 화면에서도 공용 PC 개인정보 안내를 표시합니다. 가능하면 실명 대신 번호나 별칭을 사용하고, 종료 시 **처음으로 돌아가기** 또는 **게임 강제 종료**를 눌러 저장 기록을 삭제하세요.

## 게임 규칙과 로그

- 치료제 반복 사용과 교사 화면의 자유로운 접근은 기존 운영 의도대로 유지합니다.
- `src/game/rules.ts`는 접촉·치료·라운드 정산을 부작용 없는 함수로 처리합니다.
- 로그는 처리 전/후 상태와 두 학생의 누적 승점을 각각 저장합니다. Excel은 시간순 게임 로그와 학생 현황 시트를 제공하며, 내보내기 코드는 다운로드 시점에만 불러옵니다.
- 제한 시간은 1초 이상의 정수만 허용합니다.
- 종료 확인을 취소하면 확인창을 열기 직전의 타이머 실행/정지 상태로 돌아갑니다.
- 오디오는 컨텍스트를 공유하고 재생이 끝난 노드를 해제합니다. 도입 화면 닫기·음소거 시 재생과 대기 중인 오디오 작업을 취소하고 컨텍스트를 닫습니다.
- 모든 버튼은 성격에 따라 선택·확인·이동·경고 효과음을 재생합니다.
- 교사 페이지를 처음 열면 학생에게 화면을 노출하지 말라는 안내가 표시됩니다. ‘다시 뜨지 않음’을 선택하면 같은 브라우저에서 이후 안내를 생략합니다.

기존 `REF_GENIUS_VIRUS_GAME.md`는 이전 버전의 참고 자료로 현재 구현과 차이가 있을 수 있습니다. 현재 동작은 이 README 및 소스코드를 기준으로 합니다.

## 배경 및 BGM

- 시작 화면: `bg_lobby_lab.webp`
- 설정·도입: `bg_briefing_lab.webp`. 게임 중에는 같은 이미지를 어둡게 표시해 이름과 타이머를 우선합니다. 기존 10단계 교육 이미지는 유지합니다.
- 결과: 승리 진영에 따라 `bg_result_human.webp` 또는 `bg_result_infected.webp`.
- 게임 진행 BGM: `bgm_game_suspense.mp3`. 게임 화면 진입과 함께 재생하며, 타이머 정지와 라운드 종료 화면에서도 끊기지 않습니다.
- 결과 BGM: `bgm_results_resolution.mp3`. 결과 화면 진입 시 전환합니다.
- 시작·설정·도입에는 BGM이 없습니다. `bgm_lobby_mystery`는 사용하지 않습니다.
- 우측 하단의 작은 컨트롤에 재생·일시정지 버튼, `BGM` 텍스트, 음량 슬라이더가 있습니다. 기본 음량은 20%이며 화면·라운드 전환 시 선택값을 유지하고 새로고침 시 기본값으로 돌아갑니다.
- 두 BGM은 원본 파일 전체를 반복 재생합니다. 게임에서 결과 화면으로 이동하면 결과곡으로 전환하며 중복 재생하지 않습니다. 브라우저가 자동 재생을 차단하면 재생 버튼으로 시작할 수 있고 음원 오류가 게임 진행을 막지 않습니다.
- 제공 파일은 원본 그대로 복사했으며 `src/assets/images`, `src/assets/audio`에 포함되어 외부 음원 서비스 없이 배포할 수 있습니다.

## 아이콘 제작과 적용

`ICON_PROMPTS.md`에는 대표 심볼, 양 진영, 접촉, 치료제, 타이머 상태, 라운드, 교사 도구, 기록 내보내기, BGM, 가이드, 결과 아이콘의 공통 규격과 생성 프롬프트가 있습니다. 생성 원본은 투명 PNG로 받은 뒤 윤곽을 정리해 SVG로 변환하고 16·24·32·64px에서 검수합니다.

v1.1.0에서는 `symbol_virus_game`, `emblem_human`, `emblem_infected`, `icon_treatment` PNG를 시작 화면, 게임 설명, 최초 감염자 설정, 치료제 버튼·확인창, 교사 페이지와 최종 결과에 적용했습니다. 게임 중 학생 카드에는 진영 심볼을 표시하지 않아 숨은 상태가 노출되지 않습니다.

## 보안·성능

- `npm audit` 기준 알려진 취약점 0건을 유지합니다.
- 취약점이 보고된 기존 `xlsx` 의존성을 제거하고 `write-excel-file`로 교체했습니다.
- Excel 생성 라이브러리와 10단계 도입 모달은 동적 import로 분리되어 초기 JavaScript 청크에 포함되지 않습니다.
- 외부 Google Fonts 요청을 제거해 오프라인 환경에서도 시스템 한글 글꼴로 일관되게 표시합니다.
- 앱 버전은 `package.json`에서 읽어 화면 하단에 표시합니다.
